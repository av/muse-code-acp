## Objective

Map tracked tasks to an opt-in async-task extension and safely target verified termination operations.

## Context

- Why: m9 live output and m11 workers do not represent background commands; reuse m10 ownership and m11 child identity routing.
- Milestone goal: Keep background commands visible beyond prompt completion and allow safe targeted stopping where the host supports it.
- Reference context: `src/muse-sdk-events.ts`, `src/muse-sdk.ts`, `.tmp/codex-acp/docs/async-tasks.md`, `.tmp/codex-acp/src/async-tasks/CodexBackgroundTerminalTasks.ts`.

## Steps

1. Document bilateral capability negotiation and emit a baseline tool-card fallback.
2. Resolve stop requests to the owning task/host generation; handle already-finished and unknown tasks without affecting siblings.
