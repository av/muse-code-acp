## Objective

Separate host lifetime from turn translation so compatible consecutive turns reuse their process.

## Context

- Milestone goal: Allow corrections during active work and reduce repeated startup through safely scoped host reuse.
- Why: Steering needs access to the live session; host reuse must preserve the settings and approval isolation currently provided by per-turn processes.
- Reference context: `src/muse-sdk.ts`, `src/acp-agent.ts`, `src/mcp-overlay.ts`, `.tmp/codex-acp/src/SteeringQueue.ts`, `.tmp/codex-acp/src/CodexAcpServer.ts`.
- Follow `.pm/DO_NOT_DO.md`; verify public host behavior before advertising support. Reference schema presence alone is not host acceptance evidence.

## Steps

1. Extract explicit host/session ownership and per-turn handles with deterministic subscriber cleanup.
2. Retain the host between compatible turns and release it on close/dispose and bounded idle expiration; keep failure attribution unambiguous.

## Acceptance criteria

- [x] Two compatible turns use one host process and retain conversation continuity.
- [x] Closing or disposing releases all owned processes/listeners; host death fails affected work without automatic prompt replay.

## Out of scope

- Changing legacy exec process ownership.
