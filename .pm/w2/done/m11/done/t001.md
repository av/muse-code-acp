## Objective

Read verified stored output through a bounded public route.

## Context

Promoted from w1/007 after a real Muse 1.2.1 item/readOutput call returned the exact
first 100 bytes of a 300000-byte shell output. SDK 0.1.1's missing declaration is
not host absence. Source: w1/m17/t003; [ownership](../../../../ownership-2026-09-14.md).
The existing m7 fallbacks remain valid until this delivery is verified.

## Acceptance criteria

- [x] Negotiate an explicit output-read extension on verified Muse 1.2.1; preserve original session/item/outputRef identity and return actual host bytes with encoding and media type.
- [x] Validate bounded offsets/lengths and reference ownership before reading; never fetch arbitrary URIs or infer binary data from captions. Unsupported hosts keep explicit fallback.

## Out of scope

Private output storage/URI fetching, fabricated binary bytes, MCP rich payloads
not preserved by the host, npm publication and paid provider calls.

## Completion evidence

Implemented and verified with public host reads, guarded ACP delivery, and shared read-host/item-scan helpers; see [delivery evidence](../evidence.md).
