## Objective

Remove automatic catalog hosts and observe catalogs on execution connections.

## Context

See [milestone scope](../README.md), [original 013](../source-013.md) and w2/014.

## Acceptance criteria

- [x] Session new/load/resume use only available cache snapshots; no automatic catalog-only host is spawned.
- [x] A required execution connection supplies optional bounded model/list updates without delaying turn submission or changing its provider/profile route.
- [x] Execution-overlay catalogs remain local to their owning session; base-context cache keys retain workspace, binary, environment, settings and auth identity.

## Out of scope

Native host implementation, private MSP methods, global host pools, credential-backend changes and silent data-home changes.
