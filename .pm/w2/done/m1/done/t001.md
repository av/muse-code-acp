## Objective

Make the deterministic fake host able to replay the multi-stage approval shapes the real 1.2.1 host emits, so the reconciler and watchdog can be unit-tested without a Muse install.

## Context

- `src/tests/fixtures/fake-msp.cjs` answers every `approval/decide` with `terminal: true` and never emits `approval/updated`; it encodes the single-stage model this milestone removes.
- The real shape (see this milestone's README "Issue cause"): `approval/requested` carries `subject.stages[]` with `requirementId.sourceIndex` and `resolution.kind` (`unresolved` / `known_safe`); a non-terminal decide returns `terminal: false` and is followed by `approval/updated` with `change: { kind: "stageResolved", requirementId, choiceId, decision }`, the next `currentRequirementId` and refreshed `availableChoices`; the terminal decide is followed by `approval/resolved` with `stageEvidence`. Types: `node_modules/@muse-code/sdk/dist/src/msp.d.ts` (`ApprovalRequestParams`, `ApprovalUpdatedParams`, `ApprovalDecideResult`).
- Keep the fixture public-safe: derive shapes from the types and the triage table; do not copy local paths from `artifacts/w2-004/`.
- Follow `.pm/DO_NOT_DO.md`; the fixture must reject an unoffered `choiceId` (`-32052`) and a stale `requirementId` (`-32053`) exactly as the host documents.

## Steps

1. Add a script selector (for example `FAKE_MSP_SCRIPT`) alongside the existing `FAKE_MSP_MODE`, driven by a declarative per-approval script: stage list with resolution kinds, per-stage decide result (`terminal`), emitted `approval/updated` payloads, and the terminal `approval/resolved` with stage evidence.
2. Provide scripts: `two-stage` (0 unresolved, 1 known_safe, 2 unresolved, 3 known_safe), `three-stage`, `deny-at-stage-2` (abort resolves the approval with `decision: "abort"` and a cancelled tool result, nothing executes), `choices-refresh` (an `approval/updated` that keeps the requirement but changes `availableChoices` before any decide), `decide-then-silence` (`terminal: false`, then no further frames), `userinput-settle-then-silence`, and `unknown-method` (a notification method the SDK does not know, then a normal turn).
3. Enforce `-32052` / `-32053` on decide, and keep writing every command to `FAKE_MSP_CAPTURE`.
4. Add `src/tests/fake-msp.test.ts` that drives the fixture over stdio with a minimal raw client and asserts each script's frame sequence and error codes.
